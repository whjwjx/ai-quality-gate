# Prompt 版本说明

每个版本对应一份快照 `snapshots/deepseek/prompt_<version>.jsonl`。
**换 prompt 必须重录快照**，否则回放出来的还是旧结果，准确率不会变化。

| 版本 | 用途 | 特征 | 实测准确率 |
|---|---|---|---|
| `v1` | **生产版本** | 明确字段列表、JSON 格式约束、归一化要求、注入防御指令 | 字段级 96.61% / 文档级 85.71% |
| `v2` | 反例：缺少格式约束 | 去掉了 JSON 约束、归一化要求和注入防御 | 字段级 94.92% / 文档级 78.57% |
| `v3` | 反例：极端退化 | 只给文档，不给字段定义与类型，模型自由命名 | 字段级 0% / 文档级 0% |

## v2 的发现（值得记）

去掉归一化要求后，模型会输出 `"18500/月"`、`"5年"` 这类带单位的值。
这类错误**只有 3 处**，降幅不足以跌破阈值——说明：

1. 模型本身输出结构很稳，不会因为 prompt 简化就崩
2. 真正的失败来自**单位/格式不统一**，而这类问题应该由归一化层兜住

这说明「prompt 严格」和「归一化健壮」是两道互补的防线，不能只依赖其中一个。

## v3 的用途

v3 是人为构造的极端退化，用来验证**门禁灵敏度**：证明当 prompt 严重退化时，
`eval-gate` 会因准确率为 0 而阻断合并。它不是生产候选，只是红绿实验的工具。
